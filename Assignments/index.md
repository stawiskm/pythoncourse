## 🎯 Assignment Guidelines

### How to Complete Assignments:

1. **Read the Instructions**
   - Each assignment has clear objectives
   - Review the related lecture notes first

2. **Set Up Your Environment**
   - Use Google Colab (recommended) or local Jupyter
   - Ensure required libraries are installed

3. **Work Through Problems**
   - Start with easier problems
   - Test your code frequently
   - Document your approach

4. **Check Your Work**
   - Verify outputs match expectations
   - Test edge cases
   - Ensure code is readable

### Difficulty Levels:

Each assignment contains problems at different difficulty levels:
- ⭐ **Easy** - Direct application of concepts
- ⭐⭐ **Medium** - Requires combining multiple concepts
- ⭐⭐⭐ **Hard** - Complex problem-solving and optimization
