🎯 Assignment Guidelines

How to Complete Assignments:

  1. Read the Instructions - Each assignment has clear objectives
  2. Review Related Materials - Check the lecture notes and videos first
  3. Set Up Your Environment - Use Google Colab (recommended) or local Jupyter
  4. Work Through Problems - Start with easier problems first
  5. Test Your Work - Verify outputs match expectations

Difficulty Levels:

Each assignment contains problems at different difficulty levels:

  • ⭐ Easy - Direct application of concepts
  • ⭐⭐ Medium - Requires combining multiple concepts
  • ⭐⭐⭐ Hard - Complex problem-solving and optimization
